# Windows Client CRUD endpoints

### Windows (Win) Client
#### Create
Endpoint: `POST /secured/client/Win`

#### Find all
Endpoint: `GET /secured/client/Win`

#### Find by ID
Endpoint: `GET /secured/client/Win/<client-id>`

#### Update
Endpoint: `PUT /secured/client/Win`

#### Delete
Endpoint: `DELETE /secured/client/Win/<client-id>`
