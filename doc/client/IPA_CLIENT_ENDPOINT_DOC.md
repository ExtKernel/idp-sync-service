# (Free)IPA Client CRUD endpoints

### Create
Endpoint: `POST /secured/client/IPA`

### Find all
Endpoint: `GET /secured/client/IPA`

### Find by ID
Endpoint: `GET /secured/client/IPA/<client-id>`

### Update
Endpoint: `PUT /secured/client/IPA`

### Delete
Endpoint: `DELETE /secured/client/IPA/<client-id>`
