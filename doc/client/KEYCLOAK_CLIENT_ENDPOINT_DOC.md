# Keycloak Client CRUD endpoints

### API Access Keycloak (KC) Client
#### Create
Endpoint: `POST /secured/client/API/KC`

#### Find all
Endpoint: `GET /secured/client/API/KC`

#### Find by ID
Endpoint: `GET /secured/client/API/KC/<client-id>`

#### Update
Endpoint: `PUT /secured/client/API/KC`

#### Delete
Endpoint: `DELETE /secured/client/API/KC/<client-id>`
